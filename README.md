# Mantella Living World - Followers

Mantella actions for [Nether's Follower Framework](https://www.nexusmods.com/skyrimspecialedition/mods/55653). A module of [Mantella Living World - Integration Hub](https://github.com/Abhisek571/Mantella-Living-World-Hub).

| Action | What happens |
|---|---|
| JoinParty / LeaveParty | The NPC joins or leaves your NFF party |
| WaitHere / FollowMe | Only that follower waits or follows again |
| EveryoneWait / EveryoneFollow | The whole party |
| StayPassive / FightFreely | Stays out of fights, or attacks enemies and helps allies |
| WearThis | Opens trade; what you hand over becomes their NFF outfit for where you are |

Requires: [Mantella Living World - Integration Hub](https://github.com/Abhisek571/Mantella-Living-World-Hub), [Mantella](https://www.nexusmods.com/skyrimspecialedition/mods/98631) 0.14, [Nether's Follower Framework](https://www.nexusmods.com/skyrimspecialedition/mods/55653).
